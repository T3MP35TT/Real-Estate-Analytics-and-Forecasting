# Data provenance

## Property listings

- **Local file:** `data/india_housing_prices.csv`
- **Declared source:** [India House Price Prediction on Kaggle](https://www.kaggle.com/datasets/ankushpanday1/india-house-price-prediction), dataset owner `ankushpanday1` (attribution supplied by the project owner).
- **SHA-256:** `b0032196fcf336799daf45f7fed16199ff62cf23717e6dee76911467fb1d6367`
- **Limit:** Contains listing/asking prices and property attributes, not matched property resale transactions or transaction dates. Capture the source archive's version and license before redistribution.

## NHB RESIDEX city exports

- **Source:** [NHB RESIDEX](https://residex.nhbonline.org.in/), specifically the [Dashboard (Base Year 2018)](https://residex.nhbonline.org.in/DashboardBY2018/DashboardBY2018).
- **Downloaded series:** City-wise `HPI@Assessment Prices`, including the Current-Q and Previous-Q views. The dashboard also presents a separate HPI for under-construction market prices; that is not the series selected for the combined model input.
- **Raw files:** 56 `.xls` exports in `data/nhb/`; the downloads are HTML tables saved with an `.xls` extension.
- **Merged file:** `data/processed/nhb_hpi_combined.csv`, generated by `python scripts/merge_nhb_hpi.py` from raw files in `data/nhb/`.
- **Observed source coverage:** 2,856 observations covering 28 cities, spanning June 2013 through December 2025 (51 quarters). The exports contain 1,428 `Current-Q` and 1,428 `Previous-Q` observations. No duplicate city-series-view-quarter keys or conflicting values within a key remained after merging.
- **Important source-view discrepancy:** Where both views report the same city, series, and quarter, their HPI values differ in most matched observations (1,286 of 1,479; mean absolute difference about 4.25 index points, maximum about 30.04). The exports do not explain the difference. Do not average the views or treat them as interchangeable; the wide output selects `Current-Q` consistently.
- **Schema and missingness:** Two table layouts are present (`HPI@Assessment Prices` and `HPI and carpet-area prices`). The assessment HPI index is populated across the merged observations; counts and price-per-square-foot fields are only available in the detailed layout and may also be marked unavailable in source rows. These blanks are structural/source missingness, not a reason to discard the HPI observations.
- **Output layout:** The merge script writes one row per city. The first column is `City`; each remaining column is a quarter labeled by month and year (for example, `Jun 2013`). Values are the assessment HPI index from `Current-Q` only. The state-tab workbook and state-specific CSV output are not used.
- **Interpretation:** NHB's RESIDEX has distinct registered-price, assessment-price, and under-construction market-price indices. The downloaded city files identify their table as `HPI@Assessment Prices` or `Composite Index` with carpet-area price summaries; do not describe these as individual property sale records. NHB notes that the current series uses FY 2024-25 as its base and provides linking factors for earlier series. These local files are labeled base year 2018 and end in December 2025, so check for a newer linked series before deployment.

## Reproducibility and use

The merge script parses the two observed layouts, collapses exact duplicate city-series-view-quarter entries, and creates a wide city-by-quarter table from `Current-Q`. `Previous-Q` is excluded from this one-value-per-city output because it conflicts with `Current-Q`; preserve the raw downloads if both views are needed for audit. The resulting city-level indices can support market-trend analysis; they cannot alone train a property-specific resale-price model. Re-run `python scripts/merge_nhb_hpi.py` after changing raw downloads to rebuild the combined CSV.

The HPI forecast run records the source URL and hash, CV comparison, temporal holdout metrics, and per-city forecast outputs. The listing-model run manifest separately records the source file but does not use it for its proxy targets. Download dates and export versions were not embedded in the supplied files and remain unrecorded.
